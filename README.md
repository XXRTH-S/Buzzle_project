# Buzzle

เว็บถอดเสียงและสรุปภาษาไทย เลือกรูปแบบสรุป แก้ข้อความ คลิกกลับไปฟังต้นฉบับ และดาวน์โหลด PDF ได้

โปรเจกต์ส่วนตัวสำหรับเรียนรู้และแสดงผลงาน ปัจจุบันรันผ่าน Docker บนเครื่อง ยังไม่พร้อมเปิดใช้งานสาธารณะ

## ทำอะไรได้บ้าง

- อัปโหลดไฟล์เสียงหรือวิดีโอ แล้วถอดเสียงพร้อมเวลาอ้างอิง
- แก้ไขข้อความถอดเสียง และสร้างสรุปใหม่โดยไม่ต้องถอดเสียงซ้ำ
- เลือกสรุปได้ 7 แบบ: สาระสำคัญ, ไทม์ไลน์, การประชุมทั่วไป, บอร์ดบริหาร, การอบรม, การประชุมทีม และการบรรยาย
- ดาวน์โหลดสรุปของเทมเพลตที่เลือกเป็น PDF ภาษาไทย

## ระบบที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| หน้าเว็บ | Next.js, TypeScript |
| API และงานเบื้องหลัง | FastAPI, RQ, Redis |
| ฐานข้อมูลและไฟล์ | PostgreSQL, Docker volume |
| เตรียมเสียง | FFmpeg |
| ถอดเสียง | Groq · Whisper Large V3 Turbo |
| สรุป | OpenRouter · `openrouter/free` |
| PDF | WeasyPrint พร้อมฟอนต์ไทย |

ลำดับงาน: อัปโหลด → เตรียมเสียง → ถอดเสียง → สรุปตามเทมเพลต → ดาวน์โหลด PDF

## เริ่มใช้งาน

ต้องมี Docker Desktop ที่เปิดใช้งาน Linux containers และ API key ของ Groq กับ OpenRouter

**1. สร้างไฟล์ตั้งค่า** จากโฟลเดอร์โปรเจกต์ (PowerShell):

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

**2. ใส่คีย์ใน `.env`:**

```dotenv
GROQ_API_KEY=ใส่คีย์ของคุณ
OPENROUTER_API_KEY=ใส่คีย์ของคุณ
SUMMARY_MODEL=openrouter/free
```

**3. Build และเปิดระบบ:**

```powershell
docker compose -f compose.preview.yml build api web
docker compose -f compose.preview.yml up -d
```

- หน้าเว็บ: [localhost:3210](http://localhost:3210)
- ตรวจ API: [localhost:8210/health](http://localhost:8210/health)
- เอกสาร API: [localhost:8210/docs](http://localhost:8210/docs)

เลือกเทมเพลตก่อนอัปโหลด เมื่อถอดเสียงเสร็จระบบจะสร้างสรุปให้ หากต้องการแบบอื่น ให้เลือกเทมเพลตแล้วกดสร้างสรุป จากนั้นกด **ดาวน์โหลด PDF**

หากเปลี่ยนคีย์หรือโมเดล ให้โหลดค่าใหม่:

```powershell
docker compose -f compose.preview.yml up -d --no-deps --force-recreate api worker
```

## ข้อจำกัดปัจจุบัน

- Preview รองรับเสียงไม่เกิน **5 นาที** และไฟล์ WAV หลังแปลงไม่เกิน **20 MB** แม้บางจุดใน UI ยังระบุ 60 นาที
- Groq ในโหมดนี้ยังไม่แยกผู้พูด
- โมเดลสรุปฟรีอาจติดโควตาหรือส่งผลไม่สมบูรณ์ ระบบไม่เปลี่ยนไปใช้โมเดลเสียเงินอัตโนมัติ
- Preview ใช้ฐานข้อมูลและไฟล์ใน Docker ไม่ได้เชื่อม Supabase หรือ Inngest แม้ใส่ค่าไว้ใน `.env`
- ยังต้องเพิ่มระบบล็อกอิน สิทธิ์เจ้าของไฟล์ และแก้ช่องโหว่ dependencies ก่อนเผยแพร่ออนไลน์

เสียงถูกส่งไป Groq และข้อความถูกส่งไป OpenRouter ใช้เฉพาะข้อมูลที่ได้รับอนุญาต ตรวจสรุปก่อนนำไปใช้ และอย่า commit `.env` หรือไฟล์เสียง

## โครงสร้างและเอกสาร

- `app/` — API, การถอดเสียง, เทมเพลต, PDF และ worker
- `web/` — หน้าเว็บและส่วนติดต่อผู้ใช้
- `docker/` — Dockerfiles
- `scripts/` — เครื่องมือตรวจระบบและทดสอบ
- `docs/` — รายละเอียดการออกแบบและพัฒนา
