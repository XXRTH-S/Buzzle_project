# Buzzle plush bee

The SVG geometry in `web/components/Bee.tsx` was newly authored for this project. The current mark is a front-facing, rounded honey-colored bee with petal wings, soft cocoa stripes, little arms, bright eyes and rosy cheeks. It replaces the previous message-tail/audio-bar silhouette. No stock artwork, external bee icon, traced image, or third-party character reference was used for this redesign.
